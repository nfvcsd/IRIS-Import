IRIS to TXT

Turn copied IRIS immunization records into a .txt file for import into Infinite Campus.

  1. 1Copy the records in IRIS
  2. 2Paste them in the box below
  3. 3Save to the IRIS folder and import into IC
Files save to an IRIS folder on your Desktop. The first time you save, choose your Desktop and the page makes the folder.

🔒 This page works offline. Pasted records stay on this computer and are never uploaded. These are student health records, so delete the .txt file from the IRIS folder once IC has imported it.
